# 📚 Instrucciones para utilizar el programa de reservas

> Guía rápida para iniciar y utilizar correctamente el sistema.

---

## 🖥️ Antes de comenzar

Para disponer de **todas las opciones disponibles** y visualizar correctamente todos los elementos de la interfaz, se recomienda ejecutar el programa en **Full Screen**.

> 💡 **Recomendación:** maximiza la ventana antes de comenzar a utilizar el sistema.

---

## 🔐 Usuarios de acceso

El sistema cuenta con diferentes tipos de usuario.

### 👨‍💼 Administrador — ADMIN

Para acceder con un usuario de tipo **ADMIN**, utilice las siguientes credenciales:

| Campo             | Valor   |
| ----------------- | ------- |
| 🆔 **ID**         | `ADMIN` |
| 🔑 **Contraseña** | `123`   |

El usuario administrador permite acceder a las funciones administrativas del sistema.

---

### 👨‍💻 Funcionario — FUNCIONARIO

Para acceder con un usuario de tipo **FUNCIONARIO**, utilice:

| Campo             | Valor         |
| ----------------- | ------------- |
| 🆔 **ID**         | `FUNCIONARIO` |
| 🔑 **Contraseña** | `123`         |

El usuario funcionario permite utilizar las funciones relacionadas con las reservas.

---

## 🚀 Inicio rápido

Para comenzar a utilizar el sistema:

```text
1. Ejecutar el programa
        ↓
2. Activar Full Screen
        ↓
3. Introducir el ID de usuario
        ↓
4. Introducir la contraseña
        ↓
5. Presionar el botón de ingreso
        ↓
6. Utilizar las opciones disponibles
```
